# DFPaint — 안드로이드 태블릿 드로잉 앱 (MVP)

Kotlin + OpenGL ES 3.0으로 만든 드로잉 앱입니다. 외부 라이브러리 없이 Android 프레임워크만 씁니다.

## 빌드

1. Android Studio(Koala 이상)에서 이 폴더를 엽니다.
2. Gradle 동기화가 끝나면 태블릿을 연결하고 ▶ Run을 누릅니다.
   - AGP 8.5.2 · Gradle 8.9 · Kotlin 2.0.21 · compileSdk 34 · minSdk 26
   - 에뮬레이터에서도 돌아가지만 필압·틸트는 실기기(S펜 등)에서만 확인할 수 있습니다.

## 기능

| 영역 | 내용 |
| --- | --- |
| 브러시 | 펜 · 연필(그레인) · 에어브러시 · 마커 · 지우개. 도구마다 여러 개의 보조 도구(프리셋) |
| 색 혼합 | 손끝(지나온 색을 끌고 감) · 색 늘이기 · 흐리기 · **유동화**(밀기·부풀리기·오므리기) · **물감 붓**(주색을 칠하며 캔버스 색과 섞음, 흐름 = 물감 양) (J). 강도·필압, 선택 영역·투명 픽셀 잠금 반영, 대칭 지원 |
| 도형 | 직선 · 사각형 · 타원 · 올가미 채우기 · 말풍선(안쪽 보조색 + 테두리 주색) (U). 선 / 채우기 / 선+채우기, Shift = 정사각형·정원·45°, Alt = 중심에서. 선 굵기는 보조 도구(입·출 직선 포함) |
| 텍스트 | 캔버스를 눌러 글 넣기 (T). 크기·글꼴(고딕/명조/굵은 고딕)·가로/세로쓰기·색, 줄바꿈. 텍스트 레이어로 남아 글자 위를 누르면 다시 고침, 이동 도구로 옮김, 레이어 ⋯ → 래스터화 |
| 색 | 색 카드 탭: 컬러 서클(색상 고리 + 채도·명도) · 사각형 · 중간색(네 모서리 7×7, 모서리 길게 = 주색으로) · 컬러 세트(+ = 추가, 길게 = 삭제) · 슬라이더(HSV·RGB 값, 16진수), 최근 색 |
| 보조 도구 공유 | 보조 도구를 길게 누름 → 파일로 내보내기 / 파일에서 가져오기 (.dfbrush: 설정 + 사용자 팁 이미지) |
| 브러시 설정 | 크기/불투명도/흐름/경도/간격, 필압 → 크기·농도, **필압 곡선 편집**, 기울기 → 모양·크기, 그레인, **사용자 팁 이미지**, 팁 회전(고정/진행 방향/무작위), 각도·크기 흔들림 |
| 후보정 | 세부 설정의 후보정(0~40): 펜을 떼면 획 전체를 거리 기준 가우시안으로 매끄럽게 다시 그림 (양 끝 고정, 자에 붙은 선은 제외) |
| 입·출 | 선의 시작·끝을 필압과 상관없이 가늘게 (브러시 설정 또는 세부 설정, 0~400px). 출은 펜을 뗄 때 적용 |
| 밑그림 레이어 | 레이어 ⋯ 메뉴에서 지정. 화면에는 보이지만 PNG·JPEG·GIF 내보내기와 채우기·자동 선택(모든 레이어 참조)에서 빠짐 |
| 참조 레이어 | 레이어 ⋯ 메뉴에서 지정. 채우기·자동 선택의 "참조 레이어"를 고르면 지정한 레이어(선화 등)만 보고 영역을 찾아 다른 레이어에 칠함 |
| 대칭 | 상단 바 대칭 버튼: 좌우·상하·사방·방사, 가운데 손잡이를 끌어 중심 옮기기 |
| 원근 자·동심원 자 | 상단 바 그리기 보조 → 자: 원근 1·2·3점(1점은 수평·수직, 2점은 수직도), 동심원, 평행선(두 손잡이로 방향), 방사선(집중선). 획을 시작해 조금 움직이면 가장 가까운 방향에 붙음. 소실점·중심 손잡이를 끌어 이동 |
| 입력 | 필압(감마 + 브러시별 곡선), 틸트/방향, 히스토리컬 샘플, 저지연 디스패치, 지우개 쪽 펜촉 자동 전환, 펜 버튼 = 스포이드, 호버 시 브러시 크기 원 |
| 팜 리젝션 | 스타일러스가 감지되면 손가락은 그리지 않음(설정에서 변경). 변형 상자도 손바닥으로 잡히지 않음 |
| 제스처 | 한 손가락 = 이동, 두 손가락 = 이동·확대·회전, 두 손가락 탭 = 실행취소, 세 손가락 탭 = 다시실행, 마우스 휠 = 확대 |
| 레이어 | 오른쪽 손잡이(≡)를 끌어 순서 바꾸기(폴더 드나들기 포함), **폴더(통과/일반 합성)**, **클리핑**, **투명 픽셀 잠금**, 레이어 잠금(편집 막기, 잠긴 폴더 안도), 썸네일, 합성 모드 8종, 복제/삭제/순서/폴더 드나들기/아래로 병합/병합 복사(보이는 그림을 새 레이어로)/그림 통합(밑그림은 남김), **여러 레이어 고르기**(⋯ 메뉴 → 행을 눌러 고르고 폴더로 묶기·합치기·삭제) |
| 벡터 레이어 | 레이어 카드의 곡선+ 버튼. 펜·도형으로 그린 선을 획 단위로 기억: 지우개 = 닿은 선을 통째로 지움, 이동·자유 변형하면 선 데이터도 옮겨 선명하게 다시 그림, .dfp에 저장, 레이어 ⋯ → 래스터화 |
| 내비게이터 | 상단 바 보기 → 내비게이터: 그림 전체 축소판 + 지금 화면 영역(빨간 사각형), 누르거나 끌면 그곳으로 이동, 그림이 바뀌면 0.5초마다 갱신 |
| 서브 뷰 | 상단 바 보기 → 서브 뷰: 참고 이미지 창(이동·확대·두 번 탭 맞춤), 스포이드로 주색 가져오기, 끌어 옮기기·크기 조절, 이미지·위치 기억 |
| 애니메이션 | 상단 바 필름 버튼: 애니메이션 폴더(자식 하나 = 프레임 한 장) + 아래 타임라인 바 — 이전/다음, 재생(6~24fps), 프레임 칸, 새 프레임·복제·삭제, 어니언 스킨(앞 빨강·뒤 파랑), 내보내기 → 애니메이션 GIF(긴 변 800px)·MP4 동영상(H.264, 긴 변 1280px) |
| 선 굵기 수정 | 새 도구 (Y): 벡터 레이어의 선을 문지르면 닿은 부분만 굵게 / 가늘게 (가까울수록 많이, 다시 그려 선명) |
| 레이어 효과 | 경계(테두리): 굵기 1~40px·색 / 톤(망점): 농도(회색·불투명도)를 망점으로, 간격 4~64px·각도·색 / 레이어 컬러: 밑그림을 파랑 등 한 색으로 / 용지 질감: 고운 종이·캔버스 천·거친 종이 결. / 수채 경계: 가장자리를 진하게(폭·진하기). 레이어 ⋯ 메뉴, 픽셀은 그대로 두고 합성할 때만 (그리는 중에도 바로 반영, 내보내기에 포함) |
| 레이어 마스크 | 마스크 추가/삭제/켜기·끄기/적용, 마스크 썸네일을 누르면 마스크 편집 (그리기 = 보이기, 지우개 = 가리기), 레이어를 옮기면 마스크도 함께 이동, .dfp·PSD에 저장 |
| 선택 영역 | 사각형 · 타원 · 올가미 · **자동 선택**(누른 곳과 비슷한 색 영역, 허용 오차·틈 메우기·참조 레이어), 새로/추가/빼기/교차 (Shift = 추가, Alt = 빼기), 모두 선택/해제/반전, **확장·축소·경계 흐리기**, 레이어의 불투명한 부분 선택, 선택 영역 저장·불러오기(새로/추가/빼기/교차), 선택 안에서만 칠하기, 움직이는 점선 |
| 컷 나누기 | 사각형으로 선택 → 선택 범위 런처의 "컷": 컷 폴더(흰 컷 영역 + 그 안에 클리핑된 그림 레이어 + 검은 테두리 4~20px) |
| 퀵 마스크 | 상단 바 선택 → 퀵 마스크 (Q). 선택 영역이 반투명 빨간 레이어가 되고, 붓으로 칠하면 선택·지우개로 지우면 해제, 끄면 다시 선택 영역으로 |
| 복사 · 붙여넣기 | Ctrl+C / Ctrl+X / Ctrl+V: 선택 영역(없으면 레이어 전체)을 복사·잘라내기, 붙여넣으면 같은 자리에 새 레이어 |
| 선택 범위 런처 | 선택 영역이 있으면 아래에 빠른 동작 바: 해제·반전·확장·축소·복사·잘라내기·붙여넣기·지우기·채우기·변형·퀵 마스크 |
| 변형 | **자유 변형**(이동·크기·회전·반전, Shift = 비율 유지), **자유 모서리(원근) 변형**(변형 바의 사각형 버튼: 모서리·변을 따로 끌기), **메시 변형**(변형 바의 격자 버튼: 5×5 격자점을 끌어 곡면으로 휘기, 마스크 있는 레이어는 제외, 선택 영역은 해제됨), 이동 도구 |
| 채우기 | 둘러싸고 칠하기(올가미로 감싼 안의 닫힌 칸을 한 번에), 버킷(허용 오차, 모든 레이어/현재 레이어 참조, **틈 메우기**, 영역 확장), 선택 영역 채우기 |
| 필터 · 색조 보정 | 상단 바 편집 → 필터: 색조·채도·명도, 밝기·대비, 색 반전, **레벨 보정**(입력·출력 범위, 감마), **톤 커브**(점을 끌어 곡선 편집), 그라데이션 맵(주색→보조색), 포스터화, 가우시안 흐리기, 선명하게(언샤프 마스크). 슬라이더를 움직이면 캔버스에 바로 미리보기, 선택 영역 안만, 투명 픽셀 잠금이면 알파 유지, 마스크에는 흐리기만 |
| 캔버스 편집 | 상단 바 편집 → 캔버스: 이미지 크기 변경(비율 유지·25/50/200%), 캔버스 크기 변경(기준 위치 9곳), 90°/180° 회전, 좌우·상하 반전. 모든 레이어·마스크에 적용, 실행취소 가능 |
| 그라데이션 | 선형/원형, 주색→보조색 · 주색→투명 · 프리셋(무지개·노을·하늘·바다·금속), 끝에서 멈춤/반복/거울 반복, 선택 영역 안에만 |
| 엔진 | **256px 희소 타일**(빈 곳은 메모리 0), 활성 레이어 아래 합성 캐시 + 바뀐 영역만 다시 합성 |
| 실행취소 | 타일 단위 스냅샷, 100단계 또는 512MB까지 |
| 파일 | `.dfp` v2(ZIP: 트리 JSON + 레이어 PNG, v1도 읽음), PNG·JPEG·**PSD** 열기, 이미지를 레이어로 가져오기(가운데에 넣고 바로 자유 변형) PNG·JPEG(흰 배경)·**PSD(레이어 유지)**·애니메이션 GIF 내보내기(이미지는 10~200% 크기 조절), 자동 저장 |
| 새 캔버스 | 크기 프리셋, **배경 흰색/투명/색 지정** |
| UI | 아이콘 버튼 + 길게 누르면(펜 호버도) 이름·단축키 말풍선, 상단 바 기능별 묶음, 오른쪽 패널 카드 3장(도구 속성·색·레이어, 접기 가능), **라이트/다크 테마**(설정 → 화면 테마), 패널 손잡이(⠿)로 끌어 옮기기 + 가장자리·가운데 스냅(설정에서 잠금·초기화) |
| 자동 저장 | 앱을 나갈 때 + 그리다 쉬는 동안 2분마다, 이전 자동 저장본을 10분 간격으로 5개까지 기록 (열기 → 자동 저장 기록에서 열기) |
| 성능 측정 | FPS·펜 지연 표시, A4 300dpi·50장 부하 문서, 합성 벤치마크 |
| 퀵 액세스 | 상단 바 앱 → 번개 버튼: 자주 쓰는 기능을 담는 떠 있는 버튼 창 (+ 로 아무 기능이나 추가, 길게 눌러 빼기, 위치 기억) |
| 단축키 | 모두 재지정 가능 (상단 바 → 단축키) |

## 알려진 한계 (3단계에서 다룰 것)

- 아직 실제 기기에서 빌드·실행해 보지 않았습니다. 셰이더는 glslangValidator로, Kotlin 코드는 Android API 스텁에 대한 타입 검사로만 확인했습니다.
- 벡터 레이어, 원근 가이드, 애니메이션은 없습니다. PSD는 벡터 마스크·효과·조정 레이어를 읽지 못합니다.
- 폴더를 일반 합성으로 여러 단계 겹치면 단계마다 캔버스 크기 버퍼 2장(4096²이면 약 128MB)을 씁니다.
