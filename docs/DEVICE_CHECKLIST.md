## 먼저 (앱이 켜지는지)
- [ ] 앱이 정상으로 켜지고 펜으로 그려짐 (새 셰이더 4개: 물감 붓, 용지 질감, 수채 경계, 흑백 보기)

## 그리기·도구
- [ ] 색 혼합 도구(J) → **물감 붓**: 주색이 칠해지면서 아래 색과 섞임, 흐름을 낮추면 덜 칠해짐
- [ ] 색 혼합 도구 → **유동화 밀기 / 부풀리기 / 오므리기**: 그림 모양이 밀리고 커지고 작아짐, 실행취소
- [ ] **선 굵기 수정**(Y): 벡터 레이어(레이어 카드의 곡선+ 버튼)에 선을 긋고 문지르면 그 부분만 굵게/가늘게
- [ ] 채우기 → **둘러싸고 칠하기**: 선으로 칸을 몇 개 그리고 올가미로 감싸면 닫힌 칸만 칠해짐
- [ ] 스포이드 → **현재 레이어**: 다른 레이어에 가려진 색도 집힘

## 레이어
- [ ] 레이어 ⋯ → **밑그림 레이어로**: PNG/PSD로 내보내면 빠지고, 채우기(모든 레이어)가 밑그림 선을 무시
- [ ] 레이어 ⋯ → **용지 질감** (3종) / **수채 경계**: 미리보기, 확인, 효과 끄기, 다른 효과와 함께
- [ ] 레이어 ⋯ → **병합 복사 / 그림 통합**, 실행취소
- [ ] 사각형 선택 → 선택 범위 런처의 **컷**: 컷 폴더가 생기고 "그림" 레이어에 그린 것이 컷 밖으로 안 나감

## 창·화면
- [ ] 상단 바 보기 → **내비게이터**: 축소판, 빨간 사각형이 화면 영역, 눌러서 이동
- [ ] 상단 바 보기 → **격자**(Ctrl+'), **흑백 보기**(Ctrl+Shift+G)
- [ ] 상단 바 앱 → **퀵 액세스**(번개): + 로 기능 추가, 길게 눌러 빼기, 도구 버튼으로 도구 바뀜
- [ ] 색 카드 → **슬라이더** 탭: HSV·RGB 값, 회색에서 색상 슬라이더가 튀지 않음
- [ ] Tab(UI 숨기기) 때 떠 있는 창도 함께 숨고 다시 나타남

- [ ] 상단 바 열기 → **자동 저장 기록에서 열기** (10분 이상 그린 뒤에 기록이 생김)
- [ ] 보조 도구 길게 누름 → **파일로 내보내기 / 가져오기** (.dfbrush)
